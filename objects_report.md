## Cross-Cutting Classifications

These objects belong to multiple hierarchies simultaneously:

| Object | Hierarchies |
|---|---|
| **lion** (9) | Could be animal OR heraldic object — appears in object field as a decorative/symbolic attribute |
| **bull** (6), **black bull** (1) | Same issue — animal used as object/emblem |
| **falcon** (4) | Egyptian crown element AND animal |
| **snake** (6), **serpent** (3), **cobra** (2) | Animal AND religious symbol |
| **eagle** (2) | Animal AND heraldic emblem |
| **goat** (1), **donkey** (2), **horse** (1), **deer** (1), **cat** (1), **dog** (1) | Animals appearing as objects |
| **scarab** (1), **baboon** (1) | Egyptian sacred animals / symbols |
| **skulls** (2), **severed heads** (1), **phallus** (1) | Body parts as ritual objects |
| **mirror** (40) | Divination tool AND personal object |
| **key** / **keys** / **iron key** (3 total) | Authority symbol AND functional object |

### Recommendation for Animals-as-Objects
~40+ entries use animals in the object field. These represent the animal as an **emblem, attribute, or symbolic companion** rather than a literal object. Options:
1. **Move** them to the `animals` column (if not already there)
2. **Keep** them in objects but tag with cross-cut label `animal-emblem`
3. **Duplicate** them in both columns
